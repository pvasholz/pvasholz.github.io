Usage

This component should always be at the top of the page, if it is being used as a functional navbar. All the nav options should go to a new page. It should appear the same on all the pages of the website.

Accessibility

This component was designed to use accessible colors by checking them on the WebAIM contrast checker site. The text of this component uses Montserrat, which is considered an easy to read font, mentioned here for example. The component attempts to be tab accessible only, for people who can't use a mouse. All clickable features can be reached by using the tab key.
