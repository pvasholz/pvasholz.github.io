Footer

This footer is based on a design made in Figma. It includes the standard information of the last time the site was updated and claims copyright for me.

Example

copyright Paul Vasholz | Last update: March 2025

Code


                  <small>
                    copyright Paul Vasholz | Last update: March 2025
                    </small>
                   </footer>

Usage

This component should always be at the bottom of the page, if it is being used as a functional footer. The date should be updated every month the website changes. It should appear the same on all the pages of the website.

Accessibility

This component was designed to use accessible colors by checking them on the WebAIM contrast checker site. The text of this component uses Montserrat, which is considered an easy to read font, mentioned here for example.
